I am a Software engineer who loves the intersection of high-level web development—crafting modern interfaces with JavaScript and React—and low-level logic. I’m a lifelong learner who finds beauty in scalable design and efficient algorithms. I believe code is the medium, but curiosity is the engine that drives every project I touch.
